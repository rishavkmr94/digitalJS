Google Cloud Associate Cloud Engineer Interview Questions

1. What is Google Cloud Platform (GCP)?

Google Cloud Platform is a suite of public cloud services provided by Google. It spans IaaS, PaaS, and SaaS solutions to support modern cloud-native application development and enterprise workloads. GCP leverages Google’s global fiber network for high availability and low-latency access. GCP is known for its advanced capabilities in data analytics, AI/ML, container orchestration (Kubernetes), and serverless architecture. Its unique offerings include BigQuery (serverless data warehouse), Cloud Spanner (global RDBMS), and Anthos (hybrid/multi-cloud management).

2. What services are covered under the GCP free tier?

GCP offers two types of free tiers: the 90-day, $300 trial and the Always Free tier. The Always Free tier includes services like 1 f1-micro VM per month in the US, 5 GB of Cloud Storage, 1 GB of egress, 1 million Cloud Functions invocations, and BigQuery usage (1 TB queries/month and 10 GB storage). This tier enables developers to prototype applications and test GCP services at no cost while adhering to fair-use quotas.

3. What is IAM in GCP?

Identity and Access Management (IAM) is a policy-driven service that allows granular control over GCP resources. IAM is based on roles and permissions, where roles can be primitive (Owner, Editor, Viewer), predefined (fine-grained service roles), or custom (tailored to an organization’s security model). IAM policies can be inherited through the GCP resource hierarchy, allowing consistent access control at the org, folder, or project level. IAM also integrates with Google Workspace for identity federation and supports service accounts for non-human access.

4. What is the difference between primitive roles and predefined roles?

Primitive roles (Owner, Editor, Viewer) provide broad access and are not recommended for production due to their coarse granularity. Predefined roles are curated by Google for specific services (e.g., roles/compute.instanceAdmin) and follow least privilege principles. These roles are more secure and should be used over primitive roles. You can also define custom roles to suit organizational needs by combining specific permissions and applying them at different levels of the resource hierarchy.

5. What is a service account in GCP?

A service account is a non-human identity used by applications and services to access GCP APIs securely. Each service account has a set of IAM roles that define its access scope. Service accounts can be associated with Compute Engine VMs, Cloud Functions, GKE workloads, and more. Best practices include assigning minimal permissions, rotating keys regularly, using Workload Identity Federation for on-prem access, and auditing usage via logs.

6. What is Compute Engine in GCP?

Compute Engine is GCP’s IaaS offering, providing highly customizable and scalable VMs. It supports custom machine types, GPU/TPU acceleration, live migration, and preemptible VMs for cost efficiency. Instance templates and managed instance groups enable autoscaling and load balancing. Compute Engine integrates with other GCP services like Cloud Storage, IAM, Cloud Monitoring, and VPC networks, making it suitable for general-purpose workloads to specialized compute-intensive applications.

7. What is Cloud Storage? What are its storage classes?

Cloud Storage is GCP's globally distributed object storage service optimized for durability and scalability. It supports multiple storage classes tailored to data access patterns:

  • Standard: Frequent access with low latency.
  • Nearline: Access once a month, ideal for backups.
  • Coldline: Access once a quarter, for archival.
  • Archive: Rare access, lowest cost, highest retrieval latency.

All classes offer the same APIs and durability (11 9’s), allowing seamless data lifecycle transitions. Bucket-level and object-level IAM policies control access.

8. What is the difference between Cloud Storage and Persistent Disks?

Cloud Storage is designed for unstructured data (object store), ideal for static assets, logs, and large media. Persistent Disks are block storage volumes attached to VMs, used for OS disks, databases, and apps requiring POSIX-compliant file systems. Persistent Disks come in Standard (HDD) and SSD variants, and offer snapshot and resize capabilities. Unlike object storage, they provide low-latency reads/writes for structured data use cases.

9. How do you create a VM instance using the console and CLI?

Via Console: Go to Compute Engine > VM instances > Create Instance. Choose machine type, disk image, region/zone, and network settings. Click 'Create'.

Via CLI:

gcloud compute instances create my-vm \
  --zone=us-central1-a \
  --machine-type=e2-medium \
  --image-family=debian-11 \
  --image-project=debian-cloud

This creates a VM with default network and firewall rules. For production, it’s essential to customize boot disks, enable OS Login, assign minimal IAM roles, and tag instances for fine-grained firewall rules.

10. What are regions and zones in GCP?

A region is a specific geographical location where GCP resources are hosted, and each region contains multiple isolated zones (data centers). Resources like Compute Engine instances, GKE nodes, and persistent disks are deployed within zones. To ensure high availability and fault tolerance, it’s recommended to architect applications across multiple zones or even regions using managed instance groups, multi-region Cloud Storage, and global load balancers.

11. What is the use of the gcloud CLI?

The gcloud command-line interface is the primary tool to create and manage GCP resources from terminals and CI/CD systems. It enables scripting deployments, automating infrastructure provisioning, updating IAM roles, viewing logs, and controlling billing services. Unlike the console, it supports versioning and reproducibility through configuration files and environment variables. It’s ideal for DevOps workflows.

12. What is a project in GCP?

A project is the primary unit for organizing, enabling, and managing GCP resources. Projects contain their own billing accounts, IAM policies, and quotas. They provide isolation between environments (e.g., dev, test, prod). Resources like Compute Engine instances, Cloud Functions, and Cloud Storage buckets reside within projects. Projects are tied to a unique project ID and project number and can be linked under folders and organizations for enterprise control.

13. What are labels and tags in GCP?

Labels are user-defined key-value metadata assigned to GCP resources for categorization, filtering, and cost tracking (e.g., env=prod). Tags are used primarily in VPC networking for applying firewall rules. While labels are global and support billing exports, tags are more security-focused and support resource-level policy enforcement. Labels help in organizing large-scale projects, while tags enhance security posture.

14. What is Cloud SDK?

Cloud SDK is a collection of tools for interacting with GCP services, including the gcloud, gsutil, and bq CLI utilities. It supports authentication via ADC (Application Default Credentials), managing deployments, monitoring resources, and invoking APIs. It is used in local development setups and CI/CD pipelines. SDK also supports emulators for services like Pub/Sub and Datastore, helping in offline development and testing.

15. How does GCP handle network routing?

GCP offers both system-generated and custom routing within its global VPC network. Each subnet comes with default routes (e.g., 0.0.0.0/0 to the internet), but you can define static or dynamic custom routes using Cloud Router with BGP for hybrid connectivity. GCP routes traffic using longest prefix match and applies tags and priorities. Routes can be regional or global based on design, supporting hybrid architectures and secure transit networks.

16. What is a VPC in GCP?

A Virtual Private Cloud (VPC) in GCP provides a private, secure, and scalable network environment to host your compute resources. It supports custom IP ranges, firewall rules, subnet segmentation, and peering. VPCs are global resources and can span across regions using subnets, making them flexible and ideal for hybrid and multi-region designs. They also integrate with Cloud NAT and VPNs for secure communication with on-prem or external environments.

17. How does firewall work in GCP?

Firewall rules in GCP are defined at the VPC network level and are stateful. They allow or deny traffic based on IP ranges, protocols, ports, and tags. Each rule has a priority, direction (ingress/egress), and action (allow/deny). They can be associated with instances via network tags or service accounts. GCP evaluates rules based on priority (lowest wins) and first match, and logs are available for debugging or auditing traffic.

18. What is Cloud Load Balancing?

Cloud Load Balancing in GCP distributes traffic across multiple resources using global or regional load balancers. It supports HTTP(S), SSL proxy, TCP/UDP, and internal traffic. Global HTTP(S) load balancing uses anycast IPs and automatically routes traffic to the nearest healthy backend. Load balancers are fully managed, scalable, and integrate with Cloud Armor for security and Cloud CDN for caching static content close to users.

19. What is GKE and how does it differ from Compute Engine?

Google Kubernetes Engine (GKE) is a managed Kubernetes service for deploying containerized applications. Unlike Compute Engine, which deals with VMs, GKE abstracts infrastructure using Kubernetes and focuses on container orchestration, scaling, and management. GKE handles node provisioning, patching, monitoring, and integrates with CI/CD, IAM, and workload identity. It is ideal for microservices and cloud-native workloads, whereas Compute Engine is better suited for traditional VM-based apps.

20. What is Cloud Functions?

Cloud Functions is a serverless compute service that lets you run code in response to events, such as HTTP triggers, Pub/Sub messages, or changes in Cloud Storage. It automatically scales, has no server management, and you are billed only for execution time. It supports Node.js, Python, Go, and Java runtimes. Common use cases include webhooks, data processing, and real-time ETL operations. Functions can be secured via IAM, and environment variables help with configuration.

21. What is Pub/Sub in GCP?

Cloud Pub/Sub is a messaging service that enables asynchronous communication between independent services. It follows a publisher-subscriber model, allowing decoupled systems to interact reliably. Pub/Sub provides at-least-once delivery, message ordering (with ordering keys), dead-letter topics, and push/pull subscription mechanisms. It’s widely used for event-driven architectures, data ingestion, and integration between microservices.

22. What is Cloud SQL and how is it managed?

Cloud SQL is a fully managed relational database service supporting MySQL, PostgreSQL, and SQL Server. It handles backups, patches, replication, failover, and encryption. Developers benefit from features like IAM-based auth, private IP, VPC peering, and automated performance tuning. It is best suited for transactional workloads and can be integrated with tools like Data Studio and BigQuery for analytical processing.

23. How do you connect on-prem to GCP?

You can connect on-premises infrastructure to GCP using Cloud VPN, Cloud Interconnect, or Partner Interconnect. Cloud VPN is fast to set up for encrypted tunnels over the internet, while Dedicated Interconnect offers high-throughput, low-latency private connectivity. BGP is typically used for dynamic route exchange. These solutions enable hybrid cloud strategies and secure data center integration.

24. What is Cloud NAT?

Cloud NAT (Network Address Translation) allows private Compute Engine instances without external IPs to access the internet for outbound traffic. It ensures security by keeping instances isolated while enabling software updates, API access, and telemetry reporting. Cloud NAT supports high availability, scale-out, and multiple NAT IPs, and is configured per region and subnetwork.

25. What are preemptible VMs?

Preemptible VMs are short-lived, cost-effective Compute Engine instances that are ideal for batch processing and fault-tolerant workloads. They are up to 80% cheaper than standard VMs but can be terminated by Google at any time after 24 hours. They are commonly used for rendering, Monte Carlo simulations, and parallel processing tasks that can handle interruptions.

26. What is Cloud Spanner?

Cloud Spanner is a globally distributed, strongly consistent relational database service that combines traditional RDBMS capabilities (like SQL and ACID transactions) with horizontal scalability and high availability. It is ideal for mission-critical applications that require high throughput, consistency, and low-latency reads/writes. Spanner supports automatic sharding, replication, and seamless scaling without downtime.

27. What is BigQuery and its advantages?

BigQuery is GCP’s serverless, highly scalable, and cost-effective data warehouse designed for real-time analytics. It separates storage and compute, enabling on-demand processing of petabyte-scale datasets using SQL. BigQuery provides native machine learning integration (BigQuery ML), federated querying, and support for BI tools like Data Studio and Looker. It is optimized for cost transparency and speed, using columnar storage and Dremel technology.

28. What is Cloud Monitoring and Logging?

Cloud Monitoring helps track metrics, uptime, and performance of GCP resources using dashboards, alert policies, and integrations. Cloud Logging (formerly Stackdriver Logging) captures logs from VMs, applications, and services. Together, they provide observability, traceability, and root cause analysis across distributed systems. They integrate with Pub/Sub, Cloud Functions, and third-party tools like PagerDuty and Splunk.

29. What is Cloud Armor?

Cloud Armor is a security service that protects GCP applications against DDoS attacks and enforces Layer 7 security policies. It integrates with global load balancers and uses preconfigured WAF (Web Application Firewall) rules to block threats. Cloud Armor also supports geolocation filtering, rate limiting, and threat intelligence signals to detect malicious IPs.

30. What is Anthos?

Anthos is a hybrid and multi-cloud application platform that enables organizations to modernize workloads anywhere — on-prem, on GCP, or on other clouds. It extends GKE for Kubernetes management across environments and includes features like service mesh (via Istio), config management, policy control, and security. Anthos helps enforce consistency, automate operations, and streamline app delivery pipelines across distributed infrastructures.

31. What is the Shared VPC?

Shared VPC allows multiple projects within the same organization to share a common VPC network. This promotes centralized control of network resources while allowing project-level autonomy for development teams. It improves security and connectivity across projects while simplifying firewall, subnet, and route management. The host project contains the VPC, and service projects can use its subnets via IAM bindings.

32. How is data encrypted in GCP?

GCP encrypts data at rest and in transit by default. At rest, data is encrypted using AES-256, and keys are managed via Google-managed, customer-managed (CMEK), or customer-supplied keys (CSEK). In transit, GCP uses TLS for secure communication. Google also supports Envelope Encryption and integrates with Cloud KMS for custom key management.

33. What is Cloud Run?

Cloud Run is a fully managed compute platform that runs stateless containers in response to HTTP requests. It supports any language, libraries, or binaries, provided the app is packaged as a container. Cloud Run auto-scales to zero, supports custom domains, IAM-based auth, and is integrated with CI/CD tools. It’s ideal for microservices and APIs that need event-driven, on-demand scaling.

34. What is the difference between Cloud Run, Cloud Functions, and App Engine?

Cloud Run is for containerized apps with HTTP triggers. Cloud Functions is event-driven, ideal for single-purpose functions with minimal configuration. App Engine is a PaaS for applications with auto-scaling and versioning support. Cloud Run gives the most flexibility, Functions require minimal ops, and App Engine balances both with more service features.

35. What is a managed instance group?

A Managed Instance Group (MIG) is a group of identical VM instances created from an instance template. It supports auto-healing, autoscaling, rolling updates, and integration with load balancers. MIGs are essential for deploying stateless workloads in a scalable and fault-tolerant way. They’re used with load balancers to distribute traffic and maintain high availability.

36. What is Cloud KMS?

Cloud Key Management Service (KMS) lets you manage cryptographic keys for your cloud services. It allows creation, rotation, import, and destruction of symmetric and asymmetric keys. Cloud KMS integrates with other GCP services like Compute Engine, BigQuery, and Cloud Storage to secure sensitive data using customer-managed encryption keys (CMEK). It supports HSM-backed keys, audit logging, and fine-grained IAM controls.

37. What is the difference between zonal, regional, and global resources?

In GCP, zonal resources (e.g., VM instances) are tied to a single zone, regional resources (e.g., regional persistent disks) span multiple zones within a region for high availability, and global resources (e.g., VPCs, global load balancers) are accessible across all regions. Understanding these scopes is critical for designing fault-tolerant and highly available architectures.

38. What is VPC Peering?

VPC Peering allows private IP communication between two VPC networks. It enables direct, secure, and high-performance traffic exchange without requiring a VPN or external IP. Peering is useful for microservice communication across projects, and it supports IAM-based control, but does not support transitive peering or overlapping CIDR ranges.

39. What is Cloud Interconnect?

Cloud Interconnect provides private, high-bandwidth connectivity between your on-prem data center and Google’s network. It comes in two forms: Dedicated Interconnect (10 Gbps or 100 Gbps per link directly connected) and Partner Interconnect (through a supported provider). It’s ideal for low-latency applications, data migration, and hybrid environments needing consistent performance and security.

40. What is the role of Cloud Scheduler?

Cloud Scheduler is a fully managed cron job service for triggering jobs on a schedule. It supports HTTP targets, Pub/Sub messages, and App Engine endpoints. It’s commonly used for batch jobs, periodic data syncing, reporting tasks, and invoking serverless functions at regular intervals. It supports retry policies, logging, and IAM-based security.

41. What are Cloud Endpoints?

Cloud Endpoints is an API management gateway that enables developers to deploy, monitor, and secure APIs on GCP. It supports OpenAPI and gRPC specifications and provides authentication (via Firebase Auth or API keys), quota control, and logging. Cloud Endpoints integrates with App Engine, Cloud Functions, Cloud Run, and GKE and is ideal for managing APIs across microservices.

42. What is Identity-Aware Proxy (IAP)?

IAP provides secure access to web applications and VMs running on GCP without requiring VPN. It sits in front of apps and enforces identity and context-aware access policies. It supports OAuth, 2FA, and integrates with Google Workspace or third-party identity providers. IAP simplifies zero-trust architecture and provides per-user and per-resource access logging.

43. What is the role of Cloud DNS?

Cloud DNS is a scalable, reliable, and managed DNS service that supports both public and private zones. It integrates with VPC networks and supports zone forwarding and DNS peering. It provides low-latency, high-availability DNS lookups and is often used for managing custom domains, hybrid DNS, and service discovery in GKE.

44. What is Forseti Security?

Forseti is an open-source security tool for GCP that audits and enforces policies across resources. It scans IAM permissions, checks for misconfigured firewall rules, and detects exposed services. Forseti helps enforce best practices and compliance requirements, integrates with Cloud Asset Inventory, and generates audit reports for security teams.

45. How does GCP support DevOps and CI/CD?

GCP offers tools like Cloud Build (CI/CD automation), Artifact Registry (package storage), Cloud Source Repositories (Git), and Skaffold (Kubernetes deployment). These integrate with GitHub, GitLab, and other CI/CD systems. GCP supports pipelines for code, build, test, deploy workflows and integrates with Cloud Monitoring and Error Reporting for operational feedback. Infrastructure as Code is supported through Terraform and Deployment Manager.

46. What is Cloud Build?

Cloud Build is a serverless CI/CD platform that executes builds on GCP infrastructure. It supports building and deploying artifacts (Docker containers, Java JARs, etc.) to GCP and other cloud providers. Cloud Build integrates with GitHub, GitLab, Bitbucket, and Cloud Source Repositories. It supports custom build steps using YAML configuration and can trigger pipelines on git events. Cloud Build also supports approval gates and deploys artifacts to Cloud Run, GKE, App Engine, or Firebase Hosting.

47. What is Workload Identity Federation?

Workload Identity Federation allows applications outside GCP (e.g., running on AWS, Azure, or on-prem) to securely access GCP resources without needing long-lived service account keys. It enables identity federation via trusted identity providers (OIDC, SAML) and uses short-lived access tokens, enhancing security and simplifying credential management in hybrid or multi-cloud scenarios.

48. How do you optimize costs in GCP?

Cost optimization involves using committed use discounts (CUDs), sustained use discounts (SUDs), preemptible VMs, right-sizing VM instances, and choosing appropriate storage classes (e.g., Nearline for backups). Monitoring usage with Billing Reports, setting budgets/alerts, and using tools like Recommender and Cost Table Reports can uncover savings opportunities. Moving to serverless where possible also eliminates idle resource costs.

49. What are custom roles in IAM?

Custom roles in IAM allow organizations to define fine-grained access controls tailored to their security needs. Unlike predefined roles, custom roles contain only the permissions explicitly listed during creation. They help enforce least privilege and can be assigned at the project, folder, or organization level. They are ideal when predefined roles are too permissive or restrictive.

50. What’s the difference between Cloud Deployment Manager and Terraform?

Cloud Deployment Manager is GCP’s native Infrastructure as Code (IaC) tool that uses YAML templates and Jinja2/Python for configuration. It supports declarative resource deployment and is tightly integrated with GCP APIs. Terraform, by HashiCorp, is a multi-cloud IaC tool that supports HCL syntax, modules, remote state management, and extensive community modules. Terraform is preferred for multi-cloud/hybrid environments, while Deployment Manager is simpler for GCP-only use cases.
